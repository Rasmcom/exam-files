# بنية سحابة أعمال الاختبارات

## المكونات

- **الواجهة:** React + TypeScript + Vite، واتجاه عربي كامل RTL.
- **الحركة:** Framer Motion للحركات الانتقالية والهيرو التفاعلي.
- **المصادقة:** Supabase Auth بالبريد وكلمة المرور، دون تسجيل ذاتي.
- **قاعدة البيانات:** PostgreSQL عبر Supabase.
- **الملفات:** حاوية Supabase Storage خاصة باسم `exam-files`.
- **الصلاحيات:** Row Level Security على جميع الجداول والملفات.

## نموذج العزل

المنصة مخصصة لحساب واحد. جدول `portal_owners` يحفظ معرّف ذلك الحساب، وكل سياسة RLS تشترط شرطين معًا:

1. أن يكون المستخدم الحالي مسجلاً في `portal_owners`.
2. أن تكون البيانات مرتبطة بمعرّف المستخدم الحالي نفسه.

تعطيل التسجيل العام من إعدادات Supabase مطلوب أيضًا. حتى لو أُنشئ مستخدم إضافي بطريق الخطأ، لن تمنحه سياسات قاعدة البيانات أو التخزين صلاحية الوصول إلى مساحة العمل.

## مسار الملف

تُرفع الملفات إلى مسار خاص بالشكل:

```text
{user_id}/{document_uuid}/{safe_file_name}
```

ولا يُستخدم رابط عام. عند التنزيل تُنشئ الواجهة رابطًا موقّعًا صالحًا لمدة 60 ثانية فقط.

## نموذج البيانات

```text
academic_years
  └── semesters
       └── workspace_tabs
            └── folders
                 └── documents
```

`audit_logs` يسجل الرفع، والنقل إلى السلة، والاستعادة، وتغيير المفضلة، والتنزيل.
